# Narration Studio

Windows용 로컬 나레이션 제작 앱의 설치 파일과 업데이트를 제공합니다.

## 설치

[최신 릴리스](https://github.com/Yurang2/narration-studio-releases/releases/latest)에서 설치 파일을 받으세요.

- **기존 사용자**: 앱을 종료하고 `NarrationStudio-App-<버전>.exe`를 기존 설치 폴더에 설치하세요. 기본 경로는 `D:\NarrationStudio\App`입니다.
- **새 PC**: `NarrationStudio-Runtime-<ID>.exe`를 먼저 설치한 뒤 앱 설치 파일을 같은 폴더에 설치하세요.
- 기존 실행 환경이 다른 경우에는 해당 릴리스의 실행 환경 설치 파일도 먼저 설치하세요.

0.5.3부터 로그인이나 토큰 입력 없이 새 버전을 확인합니다. 앱 상단 알림의 **지금 업데이트**를 누르면 다운로드와 검증을 거쳐 설치하고 다시 시작합니다. 두 PC 모두 처음 한 번은 0.5.3 이상을 설치하세요.

설정 → 앱 업데이트에서 현재 버전을 확인하거나 자동 확인을 끌 수 있습니다. 음성 생성은 PC 안에서 이루어지며 업데이트를 위해 대본·사용자 음성·모델을 업로드하지 않습니다.

## 배포 파일

앱 설치 파일, 실행 환경 설치 파일, `update-manifest.json`, `SHA256SUMS.txt`를 제공합니다. 실행 환경이 같으면 이후 업데이트에서는 작은 앱 설치 파일만 받습니다.

소스 코드는 별도로 관리합니다. 설치 파일에 포함된 외부 라이브러리의 라이선스 고지는 앱의 설정 → 정보에서 확인할 수 있습니다.
